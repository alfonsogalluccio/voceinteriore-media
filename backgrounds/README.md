# Foto per gli sfondi
Qui vanno le fotografie vere (persone, momenti di vita, luoghi) da usare come sfondo.
Ammesse solo: foto scattate dal proprietario oppure scaricate da siti con licenza d'uso libera
(Unsplash, Pexels) **senza** persone riconoscibili famose e senza marchi.
Per ogni foto aggiungere una riga a `catalogo.json` con: file, soggetto, ambientazione, palette, luce, fonte/licenza.
Nello SPEC: `"bg": {"photo": "backgrounds/<file>.jpg", "meta": {...dal catalogo...}, "darken": 0.45}`.
